The question

Small inconsistencies accumulate as a product grows. Index is a study in giving a small team useful defaults without making every screen identical.

02

The direction

I built a concise set of tokens and components around three needs: readable information, predictable actions, and clear feedback.

03

What I learned

A system earns its place when it makes everyday decisions easier. The component playground demonstrates how a few shared rules hold across different contexts.
