03
How to write in your record
Day 1 check — follow exactly

This is checked on Day 1. Wrong format = you rewrite before class. Keep it exact.

1
AIM → RESULT for 7 tests: Bhatia, FPS, R vs M, 16 PF, VSMS, Eysenck, Immediate Memory Span. Use the handwritten reference pages below and your class notes for the record text; print the linked PDFs/worksheets separately. Each experiment starts on a fresh page, extreme left corner. No blank lines at the top. No title above AIM.
2
Sociometry is different: For Sociometric Assessment ONLY, write TITLE → CONCLUSION (full). Do not fill “experimenter profile”.
3
Three General Introductions (separate): Psychological Testing — 3 pages · Experimental Psychology — 2 pages · Performance Tests — 2 pages. Headings for these will be given only in class; body as per notes.

✓ Do

  • One pen colour for everything — all blue or all black
  • New page for each experiment — start top-left
  • Write “Participant” — never “Subject”
  • Fix spellings: Eysenck, Psychoticism, Neuroticism
  • Bring finished file on Day 1

✕ Don't

  • No heading / title above AIM
  • No empty lines at top
  • Don't fill profiles or result scores
  • Don't mix pen colours
  • Don't skip — incomplete files not accepted
Flow — each of the 7 tests: AIM → Introduction → Materials → Procedure → Precautions → Introspection → Result — leave blank

Sociometry: TITLE → … → CONCLUSION. Introductions: write the 3 essays fully.

General introductions — 3 separate
7 pages total
01 · Psychological Testing — 3 pages
Cover these points:
  • Definition of psychological testing
  • History — China 2200 BC → Galton, Wundt → Binet-Simon 1905 → Stanford-Binet → Army Alpha/Beta (WWI)
  • Goals: diagnosis, prediction, placement, evaluation, self-understanding, research
  • Characteristics: Standardization, Reliability, Validity, Norms
  • Types of tests & Ethics

Full wording was shared in the group forwards — use that exact text. Images zip has it.

02 · Experimental Psychology — 2 pages

Controlled experimentation to understand mental processes. Include strengths + critiques: ecological validity, replication crisis — yet it remains the rigorous empirical core.

Keep to 2 pages as per class notes.

03 · Performance Tests — 2 pages

Tests that require doing not writing — e.g., Bhatia’s Battery. Nature, uses, advantage over paper-pencil tests.

Keep to 2 pages as per class notes.

07
How your record should look
Page setup
  • A4 one-side ruled — ruled side only
  • Every experiment on a fresh page
  • Start at top-left corner — no gap, no title above AIM
  • One experiment = continuous until RESULT
  • Use file + pins — don't staple before correction
Writing style
  • Neat handwriting, one pen colour throughout
  • Headings: AIM, INTRODUCTION, MATERIALS, PROCEDURE, PRECAUTIONS, INSTRUCTIONS, SCORING, INTROSPECTION, RESULT
  • Leave RESULT blank — no scores
  • Clean margins; whitener sparingly
  • Pencil page numbers after correction

09
FAQ — quick answers
Do I write the title above AIM?
No — for the 7 tests start directly with AIM. Only Sociometry needs TITLE.
Blue for one test, black for another?
No. Pick one colour — use it for all 7 tests + 3 intros.
Spelling mistake in the PDF?
Correct it: Psychoticism / Neuroticism / Eysenck and write Participant not Subject.
How many pages total?
~100 sheets is safe: 7 tests × 8–12 pages + Sociometry + 3 intros (7 pages) + front pages. Keep 10 extra.
